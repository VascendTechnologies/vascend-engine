## Vascend Engine 1.0.0

The first public release of Vascend Engine: a native Windows workspace for desktop customization, community extensions and AI agent integrations.

### Highlights

- Compact, clickable extension cards with search, filters, sorting and activation switches.
- Install community plugins directly from public GitHub repositories or local folders.
- Conflict checks for declared incompatibilities and overlapping exclusive resources.
- Verified Vascend Technologies extension, disabled by default, with appearance, taskbar, island, widgets, Windows, editor and terminal settings.
- Optional Claude usage and Vascend IDE AI agent integrations.
- Read-only settings for disabled extensions and optional restoration when disabling.
- Bundled Vascend Grotesk Mono in Regular, Medium and SemiBold.
- English by default, with a persistent EN / IT selector, visible flags and a sliding morph indicator.
- Dark Vascend styling, custom vector icons, segmented internal navigation and animated pixel scenery.
- Fixes for Wi-Fi signal reporting, custom menus and the window's transparent corners and bottom frame.

### Install or update

**Windows 10 version 2004 or newer, x64.**

Download `VascendEngine-1.0.0-win-x64.zip`, extract all files and run **Install.cmd**. The package includes .NET 8; no SDK, separate runtime installation or administrator access is required. A Start menu shortcut is created.

Close Engine and its desktop component before updating. Existing settings and extension state are preserved, and previous binaries are backed up. New installations leave Vascend Technologies disabled until you enable it.

`SHA256SUMS.txt` contains the ZIP's SHA-256 checksum.

### Extension compatibility

Supports Engine extension API 1. Declarative manifests provide settings pages; custom behavior requires a prebuilt .NET WPF plugin. Claude Code plugins use a different format. Conflict detection relies on plugin declarations.

See the [README](https://github.com/VascendTechnologies/vascend-engine#readme) and [extension API guide](https://github.com/VascendTechnologies/vascend-engine/blob/main/docs/EXTENSIONS.md).
